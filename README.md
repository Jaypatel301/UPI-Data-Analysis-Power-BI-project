# UPI-Data-Analysis-Power-BI-project
Interactive UPI Transactions Analysis dashboard built with Power BI, featuring data transformation, synchronized slicers, bookmarks, monthly transaction &amp; balance analysis, and matrix-based city, currency and month analysis.
